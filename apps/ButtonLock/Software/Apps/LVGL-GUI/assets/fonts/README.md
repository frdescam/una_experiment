# Fonts

These LVGL font files are copied unchanged from the UNA SDK
(`Examples/Apps/RunLVGL/Software/Apps/LVGL-GUI/assets/fonts/`, SDK commit
`b5749dc4`), where they were converted with `lv_font_conv` from the Poppins
TTFs that ship with the SDK's Running example. The command line used is in the
header comment of each file.

| File | Face | Glyphs |
|---|---|---|
| `poppins_semibold_60.c` | Poppins SemiBold 60 px, 2 bpp | space to `:` and `A M O P e n p` |
| `poppins_semibold_20.c` | Poppins SemiBold 20 px, 2 bpp | printable ASCII |
| `poppins_regular_18.c`  | Poppins Regular 18 px, 2 bpp | printable ASCII |
| `poppins_regular_14.c`  | Poppins Regular 14 px, 2 bpp | printable ASCII |
